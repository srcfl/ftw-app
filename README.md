# Access on the iPhone: pictures for srcfl/ftw-app#76

The demo, photographed by `FTWUITests/AccessTour` on an iPhone SE (3rd generation, Touch ID) and an iPhone 17 Pro Max (Face ID), light and dark, English and Swedish, after the security review. The Pro Max pictures are halved.

`e2e-iphone-17-pro-max/` is `FTWUITests/AccessE2E` against a local FTW Cloud (srcfl/ftw-cloud main, ftwkeysd with a file key) and a Core box from srcfl/ftw master b5686357: the code, the offer from the real consent page (127.0.0.1, so not verified, with the owner's "I started this myself"), Face ID done, the box's roster, and the list after Remove.
